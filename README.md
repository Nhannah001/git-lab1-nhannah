# git-lab1-nhannah
Repository made for lab 1 of Intro to Source Control (feedback/memo in README)
1. The files show as untracked as they did not exist at the time of the most recent commit.
2. git diff provides the list of changes made to the files since the most recent commit.
3. git restore sets a file back to the most recent committed version, allowing you to undo changes made to said file.
4. git revert undid the most recent commit, whereas git restore overwrites changes made since the most recent commit. git revert also opens the vim editor.
